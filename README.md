# Alterra Labs concept

An unofficial design concept by Gaurav Basantani ([gauravbasantani.com](https://gauravbasantani.com)): a grading screen where a clinician replays an AI agent's run, marks where its judgment failed, and turns each mark into a scoring rule. It is not affiliated with or endorsed by Alterra Labs. The patient, run and numbers are made up and simplified, and nothing here is medical advice. Live page: https://gauravbasantani.github.io/alterra-concept/
